## Report a problem

1. [Open a new issue](../../issues/new/choose) and pick **Bug report**.
2. Choose the app, and fill in your app version and your Homey model.
3. Add what helps to find the cause:
   - **The app's own diagnostics report**, when the app has one (for example Narwal: **Apps → Narwal → Configure → Diagnostics → Run diagnostics → Copy report**). It leaves out IDs, addresses and your account.
   - **Or the Log ID of a Homey diagnostics report**: in the Homey app, **Settings → Apps → the app → Send diagnostics report**, then copy the Log ID it shows.

## Privacy

Issues here are public. Do not paste your email address, passwords, codes, device IDs, IP addresses, serial numbers or room names. The apps' own diagnostics reports already leave these out.

## Other requests

- **A feature or improvement:** pick **Feature request**.
- **A device or model that is not supported yet:** pick **New device or model**.
- **A question:** ask in the app's Homey Community thread when there is one, or open a feature request.
